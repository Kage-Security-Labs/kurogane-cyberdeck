# Mockups

Source files for the Kurogane K-7 design canvas: https://claude.ai/artifact/3ujy5RqSvhuW7s7H4iZmoM

| File | Shows |
|------|-------|
| `Main.dc.html` | Front view with GNSS/LoRa and SDR modules docked |
| `Rear.dc.html` | Rear hatches, DeckBus module and pinout |
| `BareFront.dc.html` | Front in bare bead-blasted aluminium |
| `Mainboard.dc.html` | Mainboard top and bottom, every part placed |
| `Boards.dc.html` | Input board, module board, pogo board, battery pack |
| `Exploded.dc.html` | Exploded stack-up, back shell to front frame |

These `.dc.html` files need the canvas runtime and won't render by opening them in a browser.
`renders/` holds the animated GIFs and stills used in the README, generated by `tools/render_readme_media.py`.
